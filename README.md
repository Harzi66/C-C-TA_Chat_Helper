# C&C-TA Chat Helper - HE

Chat Helper für **C&C: Tiberium Alliances**.

Der Chat Helper erleichtert die Verwendung von BB-Codes im Spielchat und in Nachrichten.

### Funktionen

- Automatische Erkennung und Formatierung von Koordinaten
- Automatische Erkennung und Formatierung von URLs
- Player- und Allianz-Tags
- BB-Codes für:
  - Fett
  - Kursiv
  - Unterstrichen
  - Durchgestrichen
- Tastenkürzel für die wichtigsten Funktionen
- Kontaktliste für Whisper
- Automatische Whisper-Namensvervollständigung
- `/chelp` für eine Übersicht der verfügbaren Funktionen

### Tastenkürzel

| Tastenkürzel | Funktion |
|---|---|
| `Alt + 1` | Koordinaten und URLs automatisch taggen |
| `Alt + 2` | URL einfügen |
| `Alt + 3` / `Alt + P` | Player-Tag |
| `Alt + 4` / `Alt + A` | Allianz-Tag |
| `Alt + B` | Fett |
| `Alt + I` | Kursiv |
| `Alt + U` | Unterstrichen |
| `Alt + S` | Durchgestrichen |
| `Alt + 0` | Tags entfernen |
